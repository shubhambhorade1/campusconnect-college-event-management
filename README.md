## 👨‍🎓 Student Features

Students can:

1. Create an account
2. Login to CampusConnect
3. Explore upcoming events
4. Search events
5. Filter events by category
6. Register for events
7. View registered events
8. Cancel registrations
9. Update their profile
10. Logout securely

---

## 👨‍💼 Admin Features

Administrators can:

* View total events
* View students
* View registrations
* Create new events
* Edit existing events
* Delete events
* Manage student registrations
* Export registration data
